# 📊 Sales Data Analysis using Python

## 🚀 Project Overview

This project demonstrates an end-to-end Sales Data Analysis workflow using Python. A realistic sales dataset containing 1,000 records was generated, cleaned, analyzed, and visualized to answer key business questions.

The objective of this project was not only to practice Python and Pandas but also to understand how data analysis helps transform raw data into meaningful business insights.

---

## 🎯 Objectives

* Generate a realistic sales dataset
* Explore and clean the data
* Perform business-focused analysis
* Visualize sales trends and insights
* Prepare a professional portfolio project

---

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Jupyter Notebook

---

## 📂 Dataset Information

The dataset contains 1,000 sales records with the following fields:

* Order ID
* Customer Name
* Product
* Category
* Quantity
* Unit Price
* Total Sales
* Discount
* Payment Method
* City
* Date

---

## 📈 Business Questions Solved

* What is the total revenue generated?
* Which city generated the highest revenue?
* Which products generated the highest revenue?
* Which category performed the best?
* Who are the top customers?
* What are the daily and monthly revenue trends?
* How are customer order values distributed?
* Are there any outliers in the sales data?
